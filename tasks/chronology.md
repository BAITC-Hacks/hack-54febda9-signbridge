# Хронология командных задач

Записи добавляются в конец по дате в формате ISO `YYYY-MM-DD`. Пользователь формулирует новые задачи по результатам исследований; не создавать их заранее. После получения задачи добавить её чеклист в файл соответствующего разработчика и зафиксировать событие здесь. Историю не перезаписывать: при изменении объёма или статуса добавить новую запись, а актуальные чеклисты обновить в соответствующем файле задачи.
